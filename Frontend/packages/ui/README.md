# `@hv/ui`

Shared design system for Happy Veggie farmer and admin apps: Tailwind 3 tokens, shadcn-style primitives, domain widgets, and shells.

## Usage

```ts
import '@hv/ui/globals.css';
import { Button, FarmGraphic, FarmerShell, AdminShell } from '@hv/ui';
```

Source exports — no separate build step. Vite resolves TypeScript from the monorepo package.
