# `@hv/ui`

Shared design tokens, primitives, domain, and admin UI for Happy Veggie farmer and admin apps.

## Usage

```ts
import '@hv/ui/tokens.css'; // optional if using package entry (tokens are imported from index)
import { Button, FarmGraphic, AdminShell } from '@hv/ui';
```

Source exports — no separate build step. Vite resolves TypeScript from the monorepo package.
